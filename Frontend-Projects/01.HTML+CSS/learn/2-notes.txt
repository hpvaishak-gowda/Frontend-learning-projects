2. Universal selector *

The * means:

* 

So this:

* {
    margin: 0;
}

means:

Remove the margin from every element.

3. Why do we use this?

Browsers give some HTML elements default styles.

For example, an <h2> normally has some default margin.

<h2>Hello</h2>

The browser automatically adds spacing around it.

If you want to control everything yourself, you can reset those defaults:

* {
    margin: 0;
    padding: 0;
}

This is commonly called a CSS reset or a simple reset.

Chapter-02

display: flex is a CSS property that turns an element into a flex container, making it much easier to arrange and align its child elements.

Basic Example
<div class="container">
  <div>Box 1</div>
  <div>Box 2</div>
  <div>Box 3</div>
</div>
.container {
  display: flex;
}

Without display: flex, the boxes stack vertically because <div> elements are block elements.

Without Flex:

Box 1
Box 2
Box 3

With Flex:

Box 1   Box 2   Box 3
Key Concepts
1. Flex Container

The parent element becomes a flex container.

.container {
  display: flex;
}

Everything inside becomes a flex item.

Container
├── Item 1
├── Item 2
└── Item 3
2. Main Axis

By default, flex arranges items horizontally.

.container {
  display: flex;
}
Main Axis →
+-------------------------+
| Item1 Item2 Item3       |
+-------------------------+
3. flex-direction

Changes the direction of the main axis.

Row (default)
.container {
  display: flex;
  flex-direction: row;
}
A B C
Column
.container {
  display: flex;
  flex-direction: column;
}
A
B
C
4. justify-content

Controls alignment along the main axis.

.container {
  display: flex;
  justify-content: center;
}
|      A B C      |

Common values:

justify-content: flex-start;
A B C
justify-content: center;
    A B C
justify-content: flex-end;
        A B C
justify-content: space-between;
A       B       C
justify-content: space-around;
  A    B    C
justify-content: space-evenly;
 A     B     C
5. align-items

Controls alignment across the cross axis (vertical by default).

.container {
  display: flex;
  align-items: center;
  height: 200px;
}
+----------------------+
|                      |
|    A B C             |
|                      |
+----------------------+

Values:

align-items: flex-start;
align-items: center;
align-items: flex-end;
align-items: stretch;
6. gap

Adds space between flex items.

.container {
  display: flex;
  gap: 20px;
}
A    B    C
7. flex-wrap

Allows items to move to the next line if there isn't enough space.

Without wrap:

.container {
  display: flex;
}
A B C D E F G (may overflow)

With wrap:

.container {
  display: flex;
  flex-wrap: wrap;
}
A B C
D E F
G
8. flex-grow

Determines how much an item should grow to fill available space.

.item1 {
  flex-grow: 1;
}

.item2 {
  flex-grow: 2;
}

Available space is divided proportionally:

+--------------------------+
| Item1 |     Item2        |
+--------------------------+

Item 2 gets twice as much extra space as Item 1.

9. flex

The shorthand:

flex: grow shrink basis;

Example:

.item {
  flex: 1;
}

Equivalent to:

flex-grow: 1;
flex-shrink: 1;
flex-basis: 0;

If all items have:

flex: 1;

they become equal widths:

+--------------------------+
| Item1 | Item2 | Item3    |
+--------------------------+
Centering an Element

One of Flexbox's most common uses is centering content.

.container {
  display: flex;
  justify-content: center;
  align-items: center;
  height: 100vh;
}

Result:

+----------------------------+
|                            |
|           Box              |
|                            |
+----------------------------+

The box is perfectly centered both horizontally and vertically.

Complete Example
<div class="container">
  <div class="box">1</div>
  <div class="box">2</div>
  <div class="box">3</div>
</div>
.container {
  display: flex;
  justify-content: space-between;
  align-items: center;
  gap: 20px;
  height: 150px;
  border: 2px solid black;
}

.box {
  width: 80px;
  height: 80px;
  background: steelblue;
  color: white;
  display: flex;
  justify-content: center;
  align-items: center;
}

This will:

Arrange the boxes in a row.
Space them evenly across the container.
Vertically center them within the container.
Leave 20px of space between each box.
Center the numbers inside each box using Flexbox again.
Quick Reference
Property	What it does
display: flex	Makes the parent a flex container
flex-direction	Sets row or column layout
justify-content	Aligns items along the main axis
align-items	Aligns items along the cross axis
gap	Adds spacing between items
flex-wrap	Allows items to wrap onto multiple lines
flex-grow	Lets items expand to fill available space
flex-shrink	Controls how items shrink when space is limited
flex-basis	Sets the initial size of a flex item
flex	Shorthand for flex-grow, flex-shrink, and flex-basis
Easy way to remember
display: flex → "Use Flexbox for layout."
flex-direction → Which way should items flow?
justify-content → Position items left ↔ right (or top ↔ bottom if flex-direction: column).
align-items → Position items top ↕ bottom (or left ↔ right if flex-direction: column).
gap → Space between items.
flex: 1 → Let items share available space evenly.
